# QQ AI Summary Bot

一个面向 QQ 群聊的信息筛选与 AI 总结项目。

它的目标不是单纯保存聊天记录，而是把群聊中的有效信息尽量结构化保存下来，并在此基础上提供：

- **消息接收与入库**：稳定记录群聊动态。
- **群聊消息查询**：快速检索历史对话。
- **资源消息解析**：支持图片、文件、表情、动画表情等。
- **AI 智能处理**：提供内容切片、降噪、聚类、分类、标签与总结。
- **前端可视化**：直观查看处理结果与后续扩展。

---

## 🎯 项目目标

这个项目希望解决的问题是：

> 群聊消息很多，但真正值得关注和回看的内容很少。  
> 我希望把群聊中有价值的信息筛出来，并在需要时快速得到摘要和原始上下文。

因此，这个项目的核心定位不是“备份群消息”，而是：**一个面向群聊信息发现、筛选与总结的工具。**

---

## ✨ 当前功能

### 1. 消息接收与存储
- 接收 **NapCat** 上报的群聊消息。
- 将消息写入数据库。
- 保留原始消息内容 `raw_message`。
- 保留清洗后的文本 `cleaned_message`。

### 2. 消息结构化解析
支持提取和保存以下信息：
- 文本消息、图片、文件。
- 普通表情与动画表情。
- 回复消息（引用）与 `@` 消息。
- 资源详情（URL、文件名、文件大小等）。

### 3. AI 处理链
项目采用以下流程对消息进行深度加工：
- **切片 (Slice)**：按时间或逻辑切分对话。
- **降噪 (Denoise)**：剔除无意义的灌水内容。
- **聚类 (Cluster)**：将相关讨论归为一簇。
- **分类与标签 (Classify & Tag)**：识别话题属性并提取关键词。
- **单簇总结 (Cluster Summary)**：生成精简的核心摘要。

### 4. 前端展示
承接后端查询与总结结果，提供直观的交互界面，方便用户追溯原始上下文。

## 🚀 运行前准备

在开始之前，你需要准备：
1. 一个已经安装并登录成功的 **NapCat**。
2. 一个可正常运行的 **Python** 环境。
3. **Node.js** 环境（用于运行前端）。
4. 一个可用的 **LLM API Key**（用于 AI 总结）。
5. 配置 `backend/.env` 文件。

### 环境变量配置

在 `backend` 目录下创建 `.env` 文件：
```ini
API_KEY=your_api_key_here
BASE_URL=your_base_url_here
MODEL_NAME=your_model_name_here
```

> **注意：**
> - `.env` 用于本地开发，包含敏感信息，**不应**提交到 Git 仓库。
> - 建议更新 `.env.example` 作为模板，方便他人了解所需配置。

## 🛠️ 启动方式

### 1. 启动后端

进入 `backend` 目录：
```bash
cd backend
```
创建并激活虚拟环境：
```bash
# 创建
python -m venv .venv

# 激活 (Windows)
.venv\Scripts\Activate.ps1
# 激活 (Linux/macOS)
source .venv/bin/activate
```
安装依赖：
```bash
pip install fastapi sqlalchemy python-dotenv uvicorn requests
```
启动后端：
```bash
fastapi dev app\main.py
```

### 2. 启动前端

进入 `frontend` 目录：
```bash
cd frontend
npm install
npm run dev
```

### 3. 启动 NapCat 并配置回调

1. 确保 NapCat 已经成功登录 QQ。
2. 在 NapCat 的 WebUI 中配置 **HTTP 消息上报**。
3. 将上报地址设置为后端的接口，例如：`http://127.0.0.1:8000/callback`。
4. 在群中发送消息，观察后端控制台是否成功接收并入库。

## 🔄 使用流程

1. **启动服务**：依次启动后端、前端及 NapCat。
2. **配置对接**：在 NapCat WebUI 配置回调地址。
3. **数据采集**：项目自动接收测试群消息并写入数据库。
4. **管理查看**：通过前端界面查看实时消息流。
5. **AI 分析**：按条件筛选特定时间段或话题的消息，触发 AI 总结。

## 💡 当前开发思路

项目按照四层结构循序渐进：
1. **信息清洗与存储**：稳定保存原始与结构化数据。
2. **信息处理**：实现筛选、分类、标签提取与价值判断。
3. **AI 总结**：根据用户需求从数据库筛选相关消息生成摘要，避免机械化总结。
4. **前端可视化**：直观展示结果，并支持下钻查看原始对话。
